# Казахские строки на вычитку носителем

Собрано `tools/seo_jsonld.py` из `tools/pages_i18n.json` (раздел `kk`) и `tools/branch_facts.json` (поля `kk`).
Правки вносить туда и пересобрать:
`python3 tools/seo_jsonld.py && python3 tools/sw_version.py`.

- `{…}` — подстановки из данных сайта, их не переводить: `{часы}` — часы точек, `{адреса}` — список адресов,
  `{точек}` / `{точек_n}` — число точек, `{кофеен}` — число кофеен 24/7, `{часы_togo}` — часы bakery to go,
  `{детские}` — где детская зона, `{намазхана}` — где намазхана, `{доставка}` `{парковка}` `{wifi}` `{бронь}`
  `{залы}` `{работа}` `{животные}` — списки «по точкам» из branch_facts.json, `{n}` / `{list}` / `{old}` — число,
  список, старая цена.
- `<br>`, `<span>`, `<a href>` — разметка, её оставить.
- Названия блюд, разделов меню и адреса точек берутся из прежнего словаря меню (`MENU_TR.kk` в `index.html`), в этот список не входят.
